# КАРАМАЗОВ — цифровой литературный музей 2.0

Интерактивный музей романа Ф. М. Достоевского «Братья Карамазовы». Русский интерфейс, полный текст без регистрации, авторский дизайн в духе книжной графики.

## Запуск

Нужны Node.js 20.9+ (рекомендуется 22 или 24), npm и современный браузер с IndexedDB.

```sh
npm ci
npm run dev
```

Открыть http://localhost:3000.

```sh
npm run typecheck
npm run verify:content
npm run build
npm start
```

`verify:content` требует Python 3 (только стандартная библиотека). Для повторной загрузки текста: `python3 scripts/import-text.py`. Обычная сборка не обращается к источнику: весь текст, изображения и шрифты включены в репозиторий.

## Возможности

- Главная музейная экспозиция, 30 профилей персонажей, 17 философских исследований, исторический контекст, галерея, страница прав.
- Полная читалка: 12 книг и эпилог, 96 глав плюс предисловие; оглавление, поиск по всему роману, подсветка совпадений, настройки размера/интервала, бумажная и ночная темы.
- IndexedDB: текущая глава/абзац, прогресс, закладки, заметки, настройки, режим без спойлеров. Без аккаунтов и внешних баз данных.
- Интерактивная карта React Flow с фильтрами отношений и доступной текстовой альтернативой, хронология с привязкой к главам, атлас 44 проверенных цитат.
- Кабинет читателя с удалением записей и экспортом тетради в JSON. Поддержан импорт резервной копии с объединением данных; автоматической синхронизации между устройствами нет.
- Режим без спойлеров включён изначально. Скрывает будущие подробности профилей/статей, события, связи, цитаты и поисковые выдержки. Имена героев и базовые вводные доступны; будущие названия глав скрыты. Переход к более поздней главе предполагает, что предыдущие прочитаны; защита не может установить фактическое прочтение. Переключатель в верхней панели открывает весь музей.
- Адаптивный интерфейс, локальные шрифты, WebP/Next Image, reduced motion, семантическая навигация, SEO metadata.

## Текст и редакционная достоверность

Источник: [Интернет-библиотека Алексея Комарова](https://ilibrary.ru/text/1199/index.html). На странице указано издание: Достоевский, Собрание сочинений в 15 томах, Л.: Наука, 1991, т. 9–10, и общественное достояние. 97 разделов, 1 810 099 символов. Полный текст хранится по главам, поисковый корпус загружается только при поиске.

Цитаты автоматически проверяются как точные подстроки главы, включая пунктуацию. Это проверка относительно электронной транскрипции, а не посимвольная сверка с печатными сканами. Подробности: [docs/text-source.md](docs/text-source.md), происхождение и SHA-256: [public/text/provenance.json](public/text/provenance.json).

Статьи — оригинальный редакционный анализ с опорой на роман и академический комментарий. Факты и интерпретации обозначены отдельно. Это образовательный проект, не критическое академическое издание. [Редакционная методика](docs/editorial.md).

## Vercel

Проект готов к стандартному импорту существующего GitHub-репозитория в Vercel: Framework Preset **Next.js**, Root Directory **.**, Install Command **npm ci**, Build Command **npm run build**. Output Directory не переопределять. Переменные окружения, платные сервисы и секреты не нужны. HTTPS хостинга обеспечивает работу браузерных API; данные читателя остаются только на его устройстве.

Production-проект Vercel: `karamazov` в команде `elcin31s-projects`. Публичный адрес: https://karamazov-eight.vercel.app . GitHub-интеграция использует ветку `main`. Не включайте `output: export`: используются стандартные Next.js маршруты и Image Optimization.

## Архитектура

- `src/app` — App Router, серверные страницы и metadata.
- `src/components` — оболочка, читалка, исследовательские инструменты, защита спойлеров.
- `src/lib/reader-store.ts` — единый клиентский store с версионированной IndexedDB и очередью сохранений.
- `src/data` — редакционные материалы, оглавление, проверенные цитаты, каталог изображений.
- `public/text` — полный корпус, поиск, журнал происхождения.
- `scripts` — воспроизводимый импорт и проверки содержимого.

При запрете IndexedDB интерфейс сообщает об ограничении и продолжает работу в памяти. Данные не синхронизируются между вкладками и устройствами. Очистка хранилища браузера удалит тетрадь — используйте экспорт и восстановление резервной копии.

## Выпуск 2.0

Редакционный редизайн на основе исследования десяти обязательных культурных и издательских проектов и дополнительного Folger. Светлая бумажная поверхность, Cormorant Garamond для заголовков, Literata для длинного чтения, Golos Text для интерфейса. Разные шаблоны каталога, досье, книжного путеводителя, статьи, галереи и судебного дела. Исследование и конкретный аудит: [docs/design-research.md](docs/design-research.md), [docs/design-audit.md](docs/design-audit.md).

- 30 персонажей (+18); шесть центральных досье по 1263–1416 слов. Факты текста, исторический контекст и редакционный анализ обозначены отдельно.
- 17 философских исследований: 9 новых тем и расширение 8 прежних; каждое более 500 слов.
- 13 книжных путеводителей по всем книгам и эпилогу, 96 самостоятельных комментариев к главам. Полный оригинал сохранён.
- 61 каталогизированный визуальный материал: сохранённые 6, добавленные 45 архивных объектов и 10 оригинальных сюжетных реконструкций. Генерации не выдаются за исторические произведения; портретный атлас считается одним произведением.
- Галерея с фильтрами, увеличением, клавиатурным lightbox и лицензиями; 18 событий с участниками, последствиями и иллюстрациями.
- Карта 30 героев и 65 связей шести типов, режим круга выбранного героя и текстовая альтернатива.
- Интерактивный суд: 12 материалов дела, показания, противоречия, разные уровни знания суда и читателя, сопоставление и личный вердикт. Вердикт не меняет факты романа.
- Шесть маршрутов; единый поиск по тексту и каталогу. Подробный индекс загружается после начала поиска, оригинальный текст — отдельным запросом.
- Совместимое расширение IndexedDB: история, избранные цитаты, сохранённые статьи, прогресс по книгам, экспорт и проверяемый импорт резервной копии. Старые закладки и заметки сохраняются.

Подробная проверка содержимого: [docs/content-audit-v2.md](docs/content-audit-v2.md). Аудит дизайна, визуальные проходы и финальная проверка публикации описаны в документах `docs/*v2.md`. Научное редактирование не заменяется автоматическим тестом: проверка литеральности цитаты выполняется относительно указанной электронной транскрипции, а не печатного скана.

Опциональные скрипты подготовки изображений (`import-archive.py`, `register-scenes.py`) требуют Pillow. Они не нужны для сборки, запуска или чтения сайта: подготовленные WebP уже включены в репозиторий. Финальная проверка выпуска: [docs/verification-v2.md](docs/verification-v2.md).
