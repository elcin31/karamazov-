# Проверки KARAMAZOV 2.0

Финальная версия существующего Next.js-приложения, без смены репозитория и Vercel-проекта. Среда: Node 24.19, Next.js 16.4.3, Chromium. Сборка и браузерные проверки выполнялись в production-режиме через `npm run build` и `npm start`.

## Содержимое

`node scripts/verify-content.mjs --write-report` проходит. Результат: 97 разделов полного романа, 96 комментариев к главам, 13 книжных путеводителей, 30 персонажей, 17 философских исследований, шесть больших досье, 44 дословные цитаты, 18 событий, 65 отношений, шесть маршрутов, 12 материалов суда и 61 изображение. Все структурированные идентификаторы и локальные файлы проверены; повторов содержательных абзацев от 25 слов не найдено. Подробности и точные объёмы: [content-audit-v2.md](content-audit-v2.md).

Буквальность цитат проверяется относительно указанной электронной транскрипции. Печатные сканы не сверялись посимвольно; литературная интерпретация не превращается в установленный исторический факт от того, что прошёл автоматический тест.

## Технические проверки

- TypeScript: успешно.
- Production build: успешно, **280 статических страниц/ресурсов**.
- `git diff --check`: успешно.
- **17 браузерных сценариев успешно**: основной набор 15 и два дополнительных сценария архива/круга героя.
- Два полных визуальных прохода, 112 основных снимков: HTTP 200, без горизонтального скролла и pageerror. [Отчёт](visual-audit-v2.md).

Сценарии проверяют полный цикл: интерфейс → JSON главы/поисковый индекс → отображение → IndexedDB → перезагрузка → восстановление. Проверены настройки читалки, точный переход из поиска и подсветка, восстановление абзаца, закладки и заметки; фильтры/клавиатурный lightbox/zoom; уровни судебного знания, сопоставление и сохранённый вердикт; ленивый глубокий поиск; импорт старой тетради и экспорт с реальным содержимым; сохранённые исследования, избранные цитаты и их удаление; мобильный круг выбранного героя.
