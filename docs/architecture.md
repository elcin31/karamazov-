# Архитектура 1.0

Приложение Next.js App Router с TypeScript. Обзорные и редакционные страницы — серверные компоненты; интерактивное состояние локализовано в клиентских читалке, карте и кабинете. Общая оболочка содержит глобальный режим без спойлеров, мобильную навигацию и сообщения об ошибках хранилища.

## Данные

`chapters.json` — единый порядок чтения. Внутренний адрес главы `5-4` означает книгу V, главу IV. Предисловие имеет адрес `preface`, эпилог — книгу 13. По этому оглавлению строятся ссылки, читалка, поиск, проверка цитат и границы спойлеров.

Текст хранится отдельными JSON по главам. Текущая глава загружается при переходе. Полный поисковый корпус загружается только по запросу поиска, затем используется повторно в текущей сессии; запросы поиска не передаются третьим лицам. Импорт воспроизводим и сохраняет SHA-256 исходных страниц.

`museum.ts` содержит оригинальные редакционные статьи, отношения и события; `quotes.json` — только проверенные буквальные фрагменты. Поля интерпретаций выделены в UI. Централизованный каталог изображений описывает автора, датировку, правовой статус, источник, изменения и назначение.

## Локальное состояние

Единый `reader-store` использует `useSyncExternalStore` и IndexedDB (`idb`, версия 1). Изменения последовательно записываются в очередь, соединение переиспользуется. Инициализация завершается до применения пользовательских изменений. При недоступности IndexedDB интерфейс работает в памяти и явно сообщает об ограничении.

Прогресс хранит отдельные текущую главу, абзац и максимальный порядковый номер прочитанной главы. Посещение более поздней главы подразумевает, что предыдущие уже прочитаны. Это пользовательский ориентир, не проверка фактического чтения. Режим без спойлеров действует в тексте результатов поиска, карте, хронологии, цитатах, подробных статьях, поздних названиях глав и сюжетной иллюстрации галереи. При явном открытии поздней главы её текст и заголовок доступны.

Кабинет экспортирует тетрадь в JSON. Между устройствами/вкладками синхронизации нет; JSON-импорт в 1.0 не реализован. Сервер не хранит данные посетителей.

## Производительность и доступность

WebP с Next Image, локальные WOFF2, отложенная загрузка React Flow только на карте. Читалка не загружает весь роман при открытии; архивные изображения загружаются лениво. Движение учитывает `prefers-reduced-motion`. Интерактивная карта дублируется текстовым списком связей и нативным выбором героя. У форм есть подписи, у кнопок-иконок — доступные имена. Адаптивные проверки выполняются браузером при 390 px.

## Развёртывание

Стандартный Next.js runtime на Vercel, без сторонней базы, OAuth, платных API и переменных окружения. Ресурсы и все материалы включены в репозиторий. `npm ci && npm run build` не требует доступа к литературным источникам или Google Fonts. Запуск через `npm start`. Домены и canonical URL задаются после выбора production-домена; выдуманный домен в metadata не используется.
