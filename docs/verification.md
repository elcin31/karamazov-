# Проверки версии 1.0

Дата: 30 октября 2026. Среда: Node 24.19.0, Next.js 16.4.3, системный Chromium, Linux. Проверка браузером выполнена на `npm start` после production-сборки, не только на dev-сервере.

## Пользовательский сценарий

Посетитель открывает музей → выбирает героя/тему или главу → получает локальный полный текст → меняет настройки, добавляет закладку/заметку → IndexedDB сохраняет данные → перезагрузка и кабинет восстанавливают читательскую тетрадь. Режим без спойлеров использует тот же прогресс во всех исследовательских инструментах.

| Граница | Результат и свидетельство |
|---|---|
| Страницы и навигация | 13 репрезентативных маршрутов возвращают HTTP 200, видимые h1; мобильное меню ведёт в энциклопедию |
| Читалка → текст | Реальные JSON глав загружаются, проверяются цитата, переход из поиска и подсветка |
| UI → IndexedDB → UI | Настройки, закладки, заметки, глава и абзац сохранены и восстановлены после перезагрузки |
| Поиск → результат | Будущие выдержки скрыты; после осознанного отключения защиты доступны и ведут в главу |
| Карта | Реальные узлы React Flow, фильтры связей, выбор героя, доступный текстовый список |
| Хронология и цитаты | Будущие события скрыты; переключатель сохраняется; тематический поиск работает |
| Кабинет → файл | Экспорт JSON скачан и проверен по содержимому; удаление заметок и закладок сохраняется |
| Мобильная версия | Все основные разделы при 390 px без горизонтального скролла; дополнительно главная, герои, источники, читалка и карта проверены при 320 px |
| Ошибки браузера | В маршрутном тесте нет pageerror; дополнительный проход по странице и ключевым маршрутам не обнаружил HTTP 4xx/5xx для ресурсов |

## Команды и результаты

- `npm run typecheck` — успешно.
- `npm run verify:content` — успешно: 12 книг, 96 глав и предисловие; 26 точных цитат; поисковый корпус совпадает с главами; все ссылки на главы, отношения и файлы иллюстраций корректны.
- `npm run build` — успешно, 131 статическая страница, без ошибок TypeScript.
- `npm run test:e2e` — **10/10 успешно**, 23,9 секунды на production-сборке. После последней корректировки контраста и фоновой предзагрузки повторные 2 маршрутных/мобильных теста также проходят (6,1 секунды).
- `git diff --check` — успешно.

Тесты входят в репозиторий: `tests/reader.spec.ts`, `tests/explore.spec.ts`, `tests/museum.spec.ts`.

## Исправления по результатам проверок

- Исправлена гонка инициализации IndexedDB: ранние действия не затираются загруженным состоянием. Соединение с базой переиспользуется, записи выполняются последовательно.
- Устранена утечка поздних названий глав в статьях, оглавлении, ссылках следующей главы и заглушках спойлеров.
- Для дневной читалки переопределён глобальный приглушённый цвет абзацев; проверены дневная и ночная темы.
- React Flow вынесен в отложенный модуль, чтобы не загружать его на страницах цитат и кабинета.
- Исправлены библиографическая ссылка и неточная подпись архивной страницы.
- Lighthouse выявил сдвиг footer при загрузке и пониженный контраст в начальном состоянии анимации. Добавлены резерв высоты экрана загрузки, загрузка основных шрифтов заранее, высокий приоритет обложки; анимация сохраняет полный контраст текста.

## Границы проверки

Браузерная автоматизация выполнена в Chromium с мобильными размерами экрана. Нативные Safari/iOS и Firefox не запускались; проверки на реальных устройствах и полевые Core Web Vitals после размещения остаются отдельным этапом. Проверка текста автоматическая относительно указанной электронной транскрипции; посимвольной сверки с печатными сканами нет. Редакционные статьи содержательны и проверены по главам, но не заявлены исчерпывающими научными исследованиями.

Production-развёртывание не создавалось. Совместимость со стандартным импортом Next.js на Vercel подготовлена; инструкции находятся в README.

## Lighthouse

Финальный мобильный лабораторный профиль, Lighthouse 13.6.0, simulated throttling. Отчёт: [lighthouse.json](lighthouse.json).

| Категория | Балл |
|---|---:|
| Performance | 88 |
| Accessibility | 100 |
| Best Practices | 100 |
| SEO | 100 |

FCP 0,8 с; LCP 3,9 с; TBT 100 мс; CLS 0. Начальный замер до исправлений: Performance 67, Accessibility 96, CLS 0,382. После исправлений сдвиг макета устранён, контраст проходит автоматический аудит. Излишняя фоновая предзагрузка ссылок главной и оболочки отключена. Показатель LCP при замедлении сети остаётся направлением дальнейшей оптимизации; эти баллы не являются полевыми Core Web Vitals и не гарантируют те же значения на другом устройстве.

Повторение измерения (после `npm run build` и `npm start`):

```sh
CHROME_PATH=/usr/bin/chromium npm exec --yes --package=lighthouse@13.6.0 -- lighthouse http://localhost:3000 --quiet --chrome-flags="--headless --no-sandbox" --only-categories=performance,accessibility,best-practices,seo --output=json --output-path=docs/lighthouse.json
```
